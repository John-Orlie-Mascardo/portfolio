02 Featured capstone

Real project.
Hands-on learning.

IoT + Web application In progress · IT expert evaluation

LitterSense.

A connected litter-box monitoring system that helps cat owners follow activity, odor, and behavior from a web dashboard.

Visit project ↗ Opens the live app · Sign-in required

What the system does

  • Records litter-box sessions and flags unusual activity.
  • Monitors odor to help identify when litter needs changing.
  • Offers live viewing and individual cat profiles.
  • Provides activity reports and AI-generated behavior insights.

My contribution

  • Manual feature checks, bug reporting, and retesting fixes.
  • Completed the hardware prototype, assembled from components.
  • Contributed to frontend, backend, and hardware-to-web integration through implementation review, testing, and troubleshooting.
  • Reviewing generated results and testing actual behavior.

Project objectives

Design, develop, and evaluate an IoT-enabled feline health monitoring system for Filipino cat owners, combining camera-equipped ESP32 hardware, multiple sensors, and a React-based Progressive Web Application (PWA).

  1. Analyze household monitoring practices and the clinical, infrastructure, and technology limitations of manual observation and global commercial platforms.
  2. Integrate a modified litter box, RFID identification, ultrasonic and gas sensors, camera modules, Firebase cloud services, and a React PWA with real-time anomaly alerts and PDF/CSV reports.
  3. Evaluate sensor accuracy and reliability, RFID identification, anomaly thresholds, and PWA functionality under simulated Philippine network conditions.
  4. Deploy the prototype in a real household and evaluate individual cats’ elimination patterns, report usability, and reliability under Philippine infrastructure constraints.

These are the study’s objectives; formal evaluation is ongoing.
